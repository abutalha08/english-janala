## 🚀 Overview

**English Janala** is a fully dynamic vocabulary learning platform built with **Vanilla JavaScript**, powered by **real-time API integration**. It goes beyond static UI by providing an interactive learning experience where users can browse lessons, explore vocabulary, search words instantly, hear pronunciations, and save favorite words.

The goal of this project is to create a smart and engaging vocabulary learning environment while implementing real-world frontend development concepts such as asynchronous data fetching, DOM manipulation, dynamic rendering, state handling, and interactive UX.

## ⚡ API Endpoints

### Get All Levels
```bash
https://openapi.programming-hero.com/api/levels/all
```

### Get Words by Level
```bash
https://openapi.programming-hero.com/api/level/{id}
```

Example:
```bash
https://openapi.programming-hero.com/api/level/5
```

### Get Word Details
```bash
https://openapi.programming-hero.com/api/word/{id}
```

Example:
```bash
https://openapi.programming-hero.com/api/word/5
```

### Get All Words
```bash
https://openapi.programming-hero.com/api/words/all
```
